# MRAD 2.0

Мод для **Arma Reforger 1.9.0.37**: динамический блокнот игровых поправок и дополнительные поправки прицелов в MRAD. Workshop / addon GUID остаётся `61E9542E592789AF`.

Версия исходников: **2.0.0**. Статус приёмки и фактически выполненные проверки приведены в [docs/VERIFICATION.md](docs/VERIFICATION.md). Успешная компиляция и автоматические проверки компонентов сами по себе не подтверждают все игровые и сетевые сценарии.

## Блокнот

`RangeCard_Notepad_AUTO.et` строит таблицу для оружия в **первом оружейном слоте (index 0)**. Оружие во втором слоте или выбранный в руках предмет не подменяют пустой первый слот. Данные берутся из текущего игрового projectile, muzzle и модификаторов оружия.

Таблица содержит три отдельные колонки: дальность, снижение в MRAD и поправку на поперечный ветер в MRAD. Шаг дальности — 100 м; предел по умолчанию — 1500 м, дополнительно исключаются строки без поддерживаемого движком решения. По умолчанию на странице 10 строк; последняя страница может быть неполной. Следующая и предыдущая страницы доступны только владельцу блокнота в руках, когда страниц больше одной.

Сервер рассчитывает строки и синхронизирует их вместе со страницей и параметрами таблицы. Наблюдателям не нужен прямой доступ к чужому магазину. Перелистывание использует кэш, а проверка изменившихся входных данных выполняется раз в 250 мс только у открытого блокнота. Render target создаётся только в руках у клиента и освобождается при закрытии, смене режима или удалении. Выделенный сервер и режим редактирования не создают render target.

Опорный ветер по умолчанию — **4 м/с**. Есть настройка текущего ветра. Плюс в колонке означает поправку вправо, минус — влево. При отсутствии пригодной native wind table и недоступности native prediction используется модель игрового `ShellMoveComponent`; она **явно помечается** внизу страницы. Модель сверена с native predictor в 360 случаях: максимальная разница — 0.002396 MRAD. Неизвестные типы движения снарядов и неподдерживаемые параметры дают сообщение об отсутствии данных ветра. Подробности проверки приведены в отчёте.

## Прицелы и управление

MRAD применяется к прицелам с собственными компонентами `MRAD_2DSightsComponent` или `MRAD_PIPSightsComponent`. Обычные прицелы не заменяются глобально. В репозитории есть готовые примеры ART II и M21 для обоих режимов.

| Клавиша по умолчанию | Действие |
|---|---|
| Стрелка вверх / вниз | Дополнительная вертикальная поправка ±0.1 MRAD |
| Стрелка вправо / влево | Дополнительная горизонтальная поправка ±0.1 MRAD |
| Левый или правый Shift + стрелка | Соответствующая поправка ±1.0 MRAD |
| Reset zeroing | Сброс дополнительных поправок; клавиша назначается пользователем |

Ввод работает в ADS у локального владельца поддерживаемого прицела. Значения хранятся целыми десятыми MRAD отдельно у каждого экземпляра и проверяются сервером. HUD показывает дополнительные поправки; штатная дальность пристрелки прицела сохраняется. Ноль MRAD означает отсутствие **дополнительного** смещения, а не отмену штатной пристрелки.

Настройки расположены в **Settings → MRAD**, бинды также доступны в **Controls → MRAD**. Используются штатные строки захвата и сохранения сочетаний. Параметры записываются в `$profile:MRAD/settings.json`; бинды сохраняет штатный InputBinding. Интерфейс переведён на 13 языков.

## Для разработчика

Открыть `MRAD/addon.gproj` в Workbench 1.9.0.37 с подключённым базовым проектом Arma Reforger. Сценарии и примеры находятся в `MRAD/Worlds`, `MRAD/Missions` и `MRAD/Prefabs/Weapons/MRAD`.

- [Техническое задание](docs/TZ_MRAD_2.0.md)
- [Подключение компонентов и примеры](docs/MODDING.md)
- [Исследование API и принятые решения](docs/RESEARCH.md)
- [Проверки, доказательства и ограничения](docs/VERIFICATION.md)
- [Изменения версии](CHANGELOG.md)

QA находится в **отдельном addon** `tools/qa/MRAD_QA`; он не входит в игровой MRAD. Автоматические проверки могут создавать диагностические сущности и закрывать свой процесс игры. Подключать этот addon следует только к отдельному проверочному профилю. Примеры запуска и границы тестов находятся в отчёте проверки.

Существующие GUID и физические пути игровых ассетов сохранены. Исправлены устаревшие `Name` пути двух `.meta`, ссылки каталога и тестовых сцен. Для исходной модели блокнота без collision geometry добавлен native box collider в prefab по измеренным размерам. Исходники установленной vanilla не включены в репозиторий. Публикация Workshop выполняется отдельно от отправки изменений в GitHub.
