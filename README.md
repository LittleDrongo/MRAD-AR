# MRAD

Мод для **Arma Reforger 1.9.0.37**: блокнот поправок (range card) и ввод поправок прицела в MRAD. Workshop / addon GUID `61E9542E592789AF`.

Версия исходников: **2.7.2**.

## Блокнот

`RangeCard_Notepad_AUTO.et` заполняется при взятии в руки по оружию держащего (текущее оружие, иначе основной слот) и заряженному магазину. Формат:

```
	M21 SWS
	7.62x51mm M118
	wind 1 m/s
	Meters	up	side	head
	100	1,3	0,06	0,00
	200	2,0	0,13	0,00
	300	2,9	0,19	0,00
	...
```

Колонки:

- **up** — снижение в MRAD (угол ствола от линии прицеливания);
- **side** — поправка на боковой ветер в MRAD **на 1 м/с** (скорость указана в строке `wind N m/s`): при фактическом ветре умножить на его скорость;
- **head** — поправка на встречный/попутный ветер той же скорости: `+` — встречный (пуля летит ниже, поднять прицел), `-` — попутный (летит выше, опустить). Встречный ветер увеличивает сопротивление воздуха и время полёта, попутный уменьшает; считается симуляцией полёта с ветром вдоль линии прицеливания.

Строка над таблицей — `wind N m/s` в опорном режиме (обе колонки рассчитаны на эту скорость) или `actual wind` в режиме текущего ветра: тогда в колонках сразу фактические поправки, `side` — со стрелкой ←/→, `head` — со знаком.

Снижение и ветер считаются симуляцией полёта (ShellMove: масса и сопротивление воздуха из префаба снаряда, высота прицела над стволом), а не ванильной таблицей прицеливания.

Значения ветра — с двумя знаками после запятой: при 1 м/с поправка мала (0,06 MRAD на 100 м, 0,61 на 800 м, 1,49 на 1500 м), одного знака не хватало. Эффект встречного/попутного ветра ещё меньше (0,00 примерно до 400 м, 0,02 на 800 м, 0,20 на 1500 м при 1 м/с) — это физика, а не ошибка; на коротких дистанциях им можно пренебречь. 1 MRAD на дальности d — это d/1000 м: 0,02 MRAD на 800 м ≈ 1,6 см по вертикали.

Опорная скорость ветра — **1 м/с** (в старых профилях 4 м/с один раз переносится на 1 м/с). Шаг 100 м, до 2000 м, 20 строк на страницу — весь диапазон 100–2000 м помещается на одном листе (шрифт 39). Считается на машине держащего, ничего не реплицируется.

Колонки `Meters / up / side / head` — четыре отдельных текстовых поля с фиксированными координатами, поэтому отступы между ними шире, чем давали табы рукописного шрифта.

Поправки (стрелки, Shift+стрелки, сброс) можно вводить **всегда, когда оружие в руках**, не только в прицеле, а также держа блокнот. Вне ADS активен неблокирующий `MRAD_NotepadContext`, поэтому заодно срабатывают и другие действия, назначенные на те же стрелки. В ADS работает обычный `MRAD_OpticsContext`, двойного шага нет. Введённые значения сохраняются в прицеле и применяются, когда игрок снова смотрит в него.

Лист с текстом есть только в LOD 0 модели `Notepad_LP.xob`, поэтому в руках блокнот держит LOD 0 (`SetFixedLOD(0)`), при убирании LOD снова свободный.

## Прицелы

Работает **с любым снайперским прицелом без правки префабов**: моддятся ванильные `SCR_2DOpticsComponent` / `SCR_2DSightsComponent`, общие для всех увеличенных прицелов (2D и PIP, ванильных и из модов). Прицел считается снайперским, если:

- стоит на снайперской винтовке (`EWeaponType.WT_SNIPERRIFLE`, ванильный `LongRangeRifle_Base`) и даёт 2x и больше;
- или стоит на винтовке / пулемёте и даёт 6x и больше.

Для такого прицела:

- 0 MRAD = линия прицеливания параллельна стволу; штатная таблица дальностей прицела («300 m», PgUp/PgDn) не действует, подсказка PgUp/PgDn скрыта;
- вертикаль поворачивает камеру прицела тем же путём, что ванильные прицелы с `EPZ_CAMERA_TURN` (сетка, 2D и PIP следуют), горизонталь добавляет такой же поворот по азимуту;
- значения хранятся у каждого экземпляра прицела на машине стрелка; на выстрел они влияют через обычное прицеливание (направление оружия синхронизируется игрой), поэтому попадания одинаковы у всех.

| Клавиша по умолчанию | Действие |
|---|---|
| Стрелка вверх / вниз | ±0.1 MRAD по вертикали |
| Стрелка вправо / влево | ±0.1 MRAD по горизонтали |
| Shift + стрелка | ±1.0 MRAD |
| Удержание | повтор шага |
| Reset zeroing | сброс (клавиша назначается пользователем) |

Каждый шаг щёлкает штатным звуком пристрелки (`SOUND_ZEROING_UP/DOWN` из `Weapons_Sights_Actions.acp`). На упоре щелчка нет.

### Исключение прицелов из MRAD

Прицел, который не должен работать по системе MRAD (своя сетка и таблица дальностей — например PSO-4), исключается без правки кода, двумя способами:

1. В префабе прицела на sights-компоненте (`SCR_2DOpticsComponent` / `SCR_2DSightsComponent` / PIP) поставить галочку **Exclude this optic from MRAD** (категория MRAD).
2. Либо добавить на ту же entity пустой компонент `MRAD_SightExclusionComponent` — для префабов, где атрибут недоступен (например, если класс компонента уже переопределён другим модом).

Для исключённого прицела MRAD не действует целиком: остаётся штатная таблица дальностей, штатная пристрелка PgUp/PgDn, штатный индикатор метров, стрелки MRAD и индикатор ветра не работают.

HUD: вместо ванильного «300 m» в правом нижнем блоке оружия (тот же виджет, шрифт и значок) выводится

```
▲ 1.3 MRAD
◀ 0.4 MRAD
```

Стрелки — ванильные значки `sortArrow*` из `icons_wrapperUI.imageset` (в шрифтах игры нет символов ←↑→↓).

### Индикатор ветра

В левом верхнем углу небольшой индикатор, как в Arma 3, без фона и обводки:

- стрелка `UI/layouts/MRAD/wind_arrow.edds` показывает, **куда дует ветер** относительно взгляда камеры (12 часов = от стрелка), поворот обновляется каждый кадр;
- цвет стрелки — цвет заливки клетки «Баллы Бофорта» из [таблицы шкалы Бофорта](https://ru.wikipedia.org/wiki/Шкала_Бофорта): `0 #FFFFFF`, `1 #AEF1F9`, `2 #96F7DC`, `3 #96F7B4`, `4 #6FF46F`, `5 #73ED12`, `6 #A4ED12`, `7 #DAED12`, `8 #EDC212`, `9 #ED8F12`, `10 #ED6312`, `11 #ED2912`, `12 #D5102D`;
- над стрелкой одна точка на каждый балл Бофорта (0–12), точная скорость в м/с не показывается; при штиле стрелка скрыта.

Индикатор **включён по умолчанию** и виден всегда, а не только в прицеле: он рисуется из фазы HUD-менеджера (`MRAD_WindHUDController`), вне прицеливания и без полного экрана. **Shift+K** — показать/скрыть, состояние сохраняется в `settings.json` (`showWindHUD`); действие есть в Controls → MRAD. Контекст ввода для него — один низкоприоритетный `MRAD_HUDContext` с одной комбинацией, чтобы не забирать у персонажа Shift/мышь.

### Задержка дыхания

**Shift** в прицеле — с любым прицелом, включая MRAD. Можно держать до **5 секунд**:

- 0.0–1.5 с — стабилизация (система стамины выключается с растущей скважностью, раскачка гаснет плавно);
- 1.5–3.5 с — стабильно;
- 3.5–5.0 с — плавный возврат в рабочее состояние: система стамины включается с падающей скважностью, раскачка возвращается к обычной без тряски камеры;
- на 5.0 с — принудительный выдох.

Не запускается, если стамина ниже 35% — после перебежки нужно отдохнуть. Вдох при нажатии, выдох при отпускании/5 с. После выдоха — 0.5 с хвост и **3 секунды** паузы.

### Совместимость с модами: оверрайды прицелов

Прицелы популярных модов, которые не должны работать по MRAD, перекрыты префабами в `MRAD/Prefabs/Weapons/Attachments/Optics/` (тот же GUID и путь, что у оригинала, поэтому мод заменяет их при загрузке):

| Префаб | Источник | Компонент с флагом |
|---|---|---|
| `1P69/Optic_1P69.et` | tacticalflava | `TF_2DPIPSights1P69Component` |
| `Optic_PSO1/PSO-1M2-01.et` | tacticalflava | `SCR_2DPIPSightsComponent` |
| `Optic_PSO1/Optic_PSO1_base.et` | RHS | `RHS_2DPIPSightsComponent` |
| `Optic_PSO1/Optic_PSO1M2_base.et` | RHS | `SCR_2DPIPSightsComponent` |
| `1p21/Optic_1P21.et` | RHS | `RHS_2DPIPSights1P21Component` |
| `1pn93/Optic_1PN93.et` | RHS | `RHS_2DPIPSightsComponent` |

Во всех стоит `m_bMRADExcluded 1`. Оверрайды для TF сделаны полной копией оригинального префаба с добавленной строкой, поэтому оптика сохраняет меш, инвентарь и все настройки. Мод не требует TF/RHS жёстко: без них эти префабы просто не используются (их классы приходят из соответствующих модов), а MRAD-логика к ним не применяется и так.

Если оригинал прицела обновляется в моде-источнике, оверрайд нужно пересобрать из новой версии префаба — иначе он вернёт старую конфигурацию.
