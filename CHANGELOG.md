# Изменения

## 2.1.0 — 2026-11-16

### Блокнот

- Вернул схему 1.x: один `RichTextWidget` `drg_Text`, исходный `NotepadSheet.layout` (шрифт Eskal, размер 48), формат карточки автора (`Meters | up mrad`, `100 - 1,3`), расчёт `GetAimHeightOfNextProjectile` по текущему оружию держащего.
- Причина «пустого/размытого» листа: лист с render target есть только в LOD 0 модели, в руках блокнот уходил в LOD 1. Теперь в руках LOD 0 зафиксирован.
- Убраны серверный расчёт, репликация таблицы, ветер и 36 ячеек Codex. Страница — локальная, 12 строк.
- «×» в калибре заменяется на «x» (в рукописном шрифте его нет).

### Прицелы

- MRAD работает на любом снайперском прицеле без префабов: modded `SCR_2DOpticsComponent` / `SCR_2DSightsComponent`. Удалены `MRAD_2DSightsComponent`, `MRAD_PIPSightsComponent`, `MRAD_ZeroingStateComponent`, RPC через PlayerController и примеры `MRAD_Optic_ARTII_*` (в тестовых мирах заменены на ванильный ART II).
- 0 MRAD = параллельно стволу, штатная таблица дальностей не действует.
- Щелчок: штатные `SOUND_ZEROING_UP/DOWN` на оружии (раньше вызывался несуществующий UI-звук `SOUND_SIGHT_ELEVATION`).
- HUD: в ванильной строке пристрелки блока оружия, стрелки — ванильные значки; подсказка PgUp/PgDn скрыта для MRAD-прицелов.

### Разработка

- Удалены устаревшие `tools/qa`, `docs/qa`, `docs/MODDING.md`, `docs/VERIFICATION.md` (описывали удалённые классы).

## 2.0.0 — 2026-11-16

Целевая версия игры и Workbench: 1.9.0.37. Подробный статус приёмки: [VERIFICATION.md](docs/VERIFICATION.md).

### Блокнот

- Выбор первого оружейного слота, проверка отсутствующих персонажа, оружия, muzzle, магазина и баллистических данных.
- Раздельные колонки дальности, снижения и ветра с одним десятичным знаком; постраничное отображение с циклическим переходом и локализованными пустыми состояниями.
- Серверное состояние страницы, настроек и рассчитанных строк; запросы через принадлежащий игроку PlayerController с проверкой владельца и режима предмета.
- Кэш входных данных; перелистывание не запускает повторный расчёт. Polling только у предмета в руках.
- Native wind table с проверкой границ, native prediction при доступности и явно обозначенный запасной расчёт.
- Render target только у открытого клиентского блокнота; освобождение при закрытии и удалении, защита editor/headless.
- Сохранены имена старых компонентов, атрибуты layout/text и AUTO prefab; удалён глобальный `modded SCR_GadgetComponent`.

### Оптика и настройки

- Компоненты 2D/PIP с отдельным реплицируемым состоянием каждого прицела, целочисленными шагами, серверными пределами, reset и HUD.
- Одна добавочная ориентация камеры согласована с native reticle misalignment; штатная пристрелка сохраняется.
- Девять действий, отдельный ADS контекст, мелкие и крупные шаги с обоими Shift.
- Native категория Controls → MRAD и вкладка Settings → MRAD, штатные строки переназначения, сохранение JSON и InputBinding.
- 50 строк интерфейса на 13 языках; четыре готовых примера ART II/M21.

### Ресурсы и разработка

- Каталог US регистрирует существующий AUTO; удалены ссылки на отсутствующие старые карточки.
- Исправлены прямые ссылки тестовых сцен на актуальные vanilla/MRAD ресурсы; удалены недоступные внешние debug entities и RHS override. Два самостоятельных WeaponComponent в showcase дополнены обязательным SignalsManagerComponent.
- GUID существующих ассетов сохранены; исправлены ошибочные пути в двух `.meta`.
- Исправлено создание физики блокнота: native box collider в prefab соответствует измеренным размерам модели; исходный XOB не изменён.
- Добавлены руководство мододела, отчёты API и проверок, отдельный QA addon и повторяемые изолированные launchers.
- Версия исходников повышена до 2.0.0. Workshop автоматически не публикуется.
